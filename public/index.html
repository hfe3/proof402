Proof402

Pay once. Prove forever. Autonomous agents send a SHA-256 result hash and receive a signed timestamped proof with verification links.

POST /api/proof/notarize

Paid primitive

Create a proof for a hash, not for a private payload. The raw output stays with the caller.

Verification

Every proof has a public badge and a machine-readable verification endpoint.

Local first

This MVP runs in demo mode locally. Mainnet x402 config is present but not claimed as deployed.
